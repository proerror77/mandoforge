Managed Agents 是主对象

Agent Registry

有哪些托管智能体，负责什么能力，当前是否在线。

Sessions

每个 agent 正在处理什么目标，输入输出和上下文是什么。

Tool Calls

调用了哪些 Ontology tools / connectors / desktop tools。

Approvals

哪些写操作、高风险动作、低置信度判断需要人确认。

Manager Agent = 观察者

Manager 不成为一个新系统，而是在 Managed Agents 页面右侧观察所有 agent。

  • 谁 idle / stuck / failed
  • 哪个 run 等审批
  • 哪个 tool 调用反复失败
  • 建议下一步，但默认不越权执行
